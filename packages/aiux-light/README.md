# AIUX Light Theme

The AIUX Light color theme from ServiceNow® Lux Lab 1.0.1, extracted unchanged as a code-free VS Code theme.

## Install

```sh
code --install-extension aiux-light-theme-1.0.0.vsix
```

Then pick **Preferences: Color Theme → AIUX Light**.

## Build

```sh
npx @vscode/vsce package
```
